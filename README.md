# Final-Project# StudyFlow — Student Task Manager

StudyFlow is a web application designed to help students organize their academic tasks, manage assignments, and keep track of upcoming deadlines.

The goal of StudyFlow is to provide students with a simple and organized platform where they can manage their schoolwork and stay focused on their academic responsibilities.


## Project Objectives

The main objective of StudyFlow is to help students manage their academic responsibilities more efficiently.

The project aims to:

1. Provide a simple platform for organizing assignments and study tasks.
2. Allow students to create and manage their tasks.
3. Help students keep track of assignment deadlines.
4. Allow students to monitor their progress by viewing their tasks.
5. Create a user-friendly website that is easy to navigate.

StudyFlow focuses on making academic task management simpler and more organized for students.



## Project Features

StudyFlow is being developed with the following features:

### 1. Homepage
- Introduces students to StudyFlow.
- Provides navigation to different sections.
- Includes buttons for adding and viewing tasks.
- Uses a simple, responsive design.

### 2. Add Task
- Allows students to create new academic tasks.
- Helps students organize assignments and deadlines.
- Currently under development.

### 3. My Tasks
- Displays tasks created by students.
- Helps students monitor their academic responsibilities.
- Currently under development.

### 4. Task Management
- Supports organizing and tracking academic tasks.
- Additional functionality will be integrated as development progresses.

## Technologies Used

StudyFlow uses the following technologies:

- HTML5: Structures the website content.
- CSS3: Styles the website and its layout.
- JavaScript: Supports application functionality.
- Node.js: Provides the server-side runtime.
- Express.js: Handles server requests and routing.
- EJS: Generates dynamic HTML pages.
- Git: Tracks changes during development.
- GitHub: Supports collaboration and version control.
